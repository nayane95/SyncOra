# SyncOra design direction
Source: the supplied product brief, sections 3, 9, 10, and 11.
Identity: a calm meeting desk with an explicit morning/evening rhythm.
Personality: precise, approachable, compact. Plain action labels.
Palette: warm neutral canvas, ink text, muted teal primary action; amber and red only for work status. Dark theme uses deep neutral surfaces with the same hierarchy.
Typography: system sans for compact, familiar daily use. Tabular numerals for hours and counts.
Layout: persistent desktop navigation; compact mobile menu; meeting roster next to work detail; chronological reporting tables.
Motif: morning/evening labels and a short vertical accent line on the active work panel.
Dials: ENERGY 2 / RHYTHM 2 / MOTION 1.
Radii: 6px controls, 12px panels, circular initials only.
Lucide icons: task, calendar, people and navigation glyphs match the required stack and the corresponding action. No decorative icon tiles.
Glass: only the topbar, to retain location while scrolling. Shadows only on dialogs.
Motion: brief focus/hover transitions, disabled for reduced-motion preferences.
No invented metrics or identities. Empty data remains empty. Initial avatars are placeholders. Product name is the wordmark.
